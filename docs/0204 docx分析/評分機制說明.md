## 一、附件三（知識庫）的欄位結構

附件三 Excel 包含以下欄位：

| 欄位 | 名稱 | 說明 | 是否參與評分 |
|------|------|------|-------------|
| **A 欄** | 類別 | 題目所屬類別（如：職業安全、環境保護） | ✅ 是（Rerank 階段） |
| **B 欄** | 行為準則 | RBA 行為準則描述 | ✅ 是（Rerank 階段） |
| **C 欄** | 關鍵字 | 題目相關關鍵字（換行分隔） | ✅ 是（Rerank 階段） |
| **D 欄** | 中文條文內容 | 完整的條文說明 | ✅ 是（RAG 主要匹配 + Rerank） |
| **E 欄** | 權責部門 | 負責單位（可多個，換行分隔） | ❌ 否（僅作為輸出） |
| **F 欄** | 目前現況/可能影響 | 公司目前執行狀況或影響說明 | ❌ 否（僅作為輸出） |
| **G 欄** | 問卷出處 | 題目來源（如：RBA、客戶自訂） | ❌ 否（僅作為輸出） |

## 二、RAG 語意搜尋評分範圍

系統使用 **RAG（Retrieval-Augmented Generation）語意搜尋**來比對附件二和附件三。

### 分數範圍

```
原始分數：0.0 - 1.0（浮點數）
顯示分數：0% - 100%（百分比）

轉換公式：
confidence = float(best_score) * 100.0
```

### RAG 搜尋流程

```
附件二題目 → RAG 語意搜尋 → 返回 Top-20 候選 → Rerank 二次排序 →
選擇最佳匹配 → 關鍵字驗證 → 三色標記
```

## 四、附件二比對評分邏輯

### 階段 1：RAG 語意搜尋

**目的**：從知識庫中找出語意相關的候選項目

- **輸入**：附件二的題目文字
- **處理**：將題目轉換為向量，在附件三向量資料庫中搜尋
- **輸出**：Top-20 候選項目（每個都有相似度分數 0-1）

**參數設定**：
```python
top_k = 20                  # 取前 20 名候選
score_threshold = 0.65      # 相關性閾值（低於此值會被過濾）
max_depts = 5               # 單題最多返回 5 個部門
```

---

### 階段 2：Rerank 二次排序

**目的**：在 RAG 返回的候選中，重新排序找出最佳答案

#### 評分公式

```python
score = (
    base_score                        # RAG 原始相似度
    + c_hit * 12                      # C 欄（類別+行為準則+關鍵字）命中加分
    + d_hit * 5                       # D 欄（條文內容）命中加分
    - generic_penalty * 2.5           # 泛用詞扣分
    - conflict_penalty * 35           # 衝突詞扣分
    - must_have_missing * 120         # 缺少必備詞扣分
)
```

#### 評分要素詳解

##### 1️⃣ **C 欄命中加分**（權重 **12**）

匹配附件三的「類別」、「行為準則」、「關鍵字」：

- **長詞權重更高**：系統使用 2-8 字滑窗抽取詞彙
  ```
  例如：
  「緊急應變演練」（6字） → 權重 6
  「應變演練」（4字）     → 權重 4

  → 優先選擇長詞，避免短詞誤匹配
  ```

- **計算方式**：
  ```python
  c_hit_score = sum(max(qk.get(w, 0), ck.get(w, 0))
                    for w in (set(qk.keys()) & set(ck.keys())))

  c_hit = c_hit_score / 4.0  # 轉換為等效命中數
  c_bonus = (c_hit ** 0.5) * 12  # sqrt 壓縮避免過高
  ```

##### 2️⃣ **D 欄命中加分**（權重 **5**）

匹配附件三的「中文條文內容」：

- **有上限壓縮**：避免長文本分數過高
  ```python
  d_hit_eff = min(d_hit, 20)  # D 欄最多吃到 20
  d_bonus = (d_hit_eff ** 0.5) * 5  # sqrt 壓縮
  ```

##### 3️⃣ **泛用詞扣分**（-2.5）

如果候選包含太多泛用模板詞，會被視為過於泛用：

**泛用詞列表**：
- **中文**：制定、流程、管理、監控、確保、政策、程序、機制、辦法、規範、作業
- **英文**：procedure, process, management, ensure, policy, monitor, mechanism, establish

**計算方式**：
```python
generic_penalty_score = count_generic(behavior + article) * 2.5
```

##### 4️⃣ **衝突詞扣分**（-35）

針對特定子概念題目，避免錯誤匹配：

| 題目類型 | 衝突詞（會被扣分） | 說明 |
|---------|-------------------|------|
| 消防設備 | drill, exercise, 演練, 演習 | 避免匹配到「消防演練」 |
| 急救設備 | drill, exercise, evacuation, 演練, 演習, 疏散 | 避免匹配到「緊急演練」 |
| 遠離危險 | grievance, complaint, water, energy, 申訴, 檢舉, 取水, 用水, 能源 | 避免匹配到「申訴機制」或「環境管理」 |

**計算方式**：
```python
conflict_penalty_score = conflict_count * 35
```

##### 5️⃣ **缺少必備詞扣分**（-120）

如果題目有明確子概念，候選答案必須包含核心必備詞：

| 子概念 | 觸發詞 | 必備詞 |
|--------|--------|--------|
| 消防設備 | fire detection, 火災偵測, 滅火器 | fire, alarm, extinguisher, detection, 火警, 滅火, 探測, 消防 |
| 緊急演練 | evacuation drill, 疏散演練 | drill, exercise, 演練, 演習 |
| 急救設備 | first aid kit, 急救箱 | first aid, aid kit, 急救, 急救箱 |
| 遠離危險 | imminent danger, 危險 | danger, safe, remove, imminent, 危險, 退避, 安全 |

**計算方式**：
```python
must_have_missing_score = missing_count * 120
```

**重要**：如果所有候選都缺少必備詞，系統會拒答（標記為紅色）。

---

### 階段 3：關鍵字驗證

**目的**：最後防線，避免語意相似但實際不相關的錯誤匹配

即使 Rerank 分數很高，系統還會檢查：

```python
verify_keyword_match(question, candidate_text, min_match=1)
```

**驗證邏輯**：
1. 從題目中抽取關鍵詞（英文 ≥3 字、中文 ≥2 字）
2. 從候選答案中抽取關鍵詞
3. 檢查是否至少有 1 個關鍵詞重疊

**如果關鍵字不匹配**：
- ❌ 即使相似度 > 70%，也會被標記為 🔴 **紅色（未匹配）**
- 原因：防止例如 "plastic" 被匹配到「機密資訊管理」這種離譜情況

---

### 階段 4：LLM 升級機制

**適用對象**：🟡 **黃色區間（55-70%）** 的匹配

**LLM 角色定位**：
- ✅ 只能把黃色升級成綠色（「加分助教」）
- ❌ 不能把綠色/黃色降級成紅色或未匹配

**處理流程**：

```
黃色區間匹配 (55% ≤ score < 70%)
  ↓
呼叫 Azure OpenAI GPT-5
  ↓
LLM 審查配對是否合理？
  ↓
  ├─ Y (合理) → 🟢 升級為綠色
  ├─ N (有疑慮) → 🟡 保持黃色
  └─ 無法解析 → 🟡 保持黃色
```

**LLM Prompt**：
```
你是一位負責 RBA 問卷題目比對的專家。
你的任務是審查「語意相似但信心分數在黃色區間（55-70）」的配對，
判斷它是否足夠合理，可以升級成綠色（高信心）。

客戶問卷題目：[題目]
RAG 系統找到的配對（相似度在 55-70% 黃色區間）：
  類別: [類別]
  行為準則: [行為準則]
  權責部門: [部門]
  條文內容: [條文節錄]

這個配對是否足夠合理，可以升級成綠色（高信心）？
- 如果你認為配對大致合理、語意相符，請回覆 'Y'
- 如果你認為配對有疑慮、不夠精確，請回覆 'N'

只需回覆 'Y' 或 'N'，不要有其他說明。
```

## 五、特殊情況處理

### 情況 1：附件二只有中文條文，沒有類別和關鍵字

**問題**：
- 附件三的 A、B、C 欄（類別、行為準則、關鍵字）是空的
- 只有 D 欄（中文條文內容）有資料

**影響**：
1. ✅ **RAG 語意搜尋仍可運作**：主要依賴 D 欄（條文內容）匹配
2. ❌ **Rerank 加分受限**：
   - C 欄命中分數 = 0（損失權重 12）
   - 只能依賴 D 欄（權重 5）
3. 📉 **最終分數會較低**：
   - 可能落在 **55-70%**（🟡 黃色區間）
   - 或者 **< 55%**（🔴 紅色區間）

**建議**：
- 🎯 **最佳實踐**：附件三應同時包含完整的類別、關鍵字和條文內容
- 📝 即使無法填寫完整，至少在 C 欄填入 2-3 個核心關鍵字

---

### 情況 2：題目過於簡短或模糊

**問題**：
- 例如：「是否有相關政策？」
- 缺乏具體語境和關鍵詞

**影響**：
- RAG 可能返回多個泛用條文（如「管理制度」、「監控流程」）
- Rerank 階段會因為泛用詞扣分
- 最終可能得到 **< 55%** → 🔴 紅色

**建議**：
- 附件二題目應盡量明確，包含關鍵領域詞彙
- 例如：「是否有消防安全政策？」而非「是否有相關政策？」

---

### 情況 3：NO 分支跳題邏輯

**問題**：
- 某些題目包含「若否，請跳至 C.7.1」的指令
- 系統需要自動判斷答案是 YES 還是 NO

**處理邏輯**：

```python
# 1. 解析題目中的跳題指令
no_skip_target = parse_no_skip_target(question)  # 例如 "C.7.1"

# 2. 檢查答案是否為 NO
is_no = is_answer_no(impact_text)  # 檢查「否」、「無」、「未執行」等

# 3. 如果答案為 NO，啟動跳題
if no_skip_target and is_no:
    skip_until_clause = no_skip_target  # 跳到 C.7.1
    # 中間的題目會被標記為 SKIP（黃色）
```

**判斷 NO 的關鍵詞**：
- **英文**：NO（獨立單字或開頭）
- **中文**：否、無、未執行、無執行、未設定、無設定、不執行、不設定、沒有、未有、無此、未建立

## 六、總結與最佳實踐

### 欄位權重總覽

| 欄位 | 權重/作用 | 影響程度 | 建議填寫完整度 |
|------|----------|---------|---------------|
| **中文條文（D 欄）** | RAG 主要匹配 + Rerank 加分 5 | ⭐⭐⭐⭐⭐ 最高 | ✅ 必填（越詳細越好） |
| **類別（A 欄）** | Rerank 加分 12 | ⭐⭐⭐ 高 | ✅ 建議填寫 |
| **關鍵字（C 欄）** | Rerank 加分 12 | ⭐⭐⭐ 高 | ✅ 建議填寫（至少 2-3 個） |
| **行為準則（B 欄）** | Rerank 加分 12 | ⭐⭐⭐ 高 | ✅ 建議填寫 |
| **權責部門（E 欄）** | 僅作為輸出 | - | 📝 必填（但不影響評分） |
| **現況影響（F 欄）** | 僅作為輸出 | - | 📝 必填（但不影響評分） |
| **問卷出處（G 欄）** | 僅作為輸出 | - | 📝 選填 |

---

### 關鍵結論

✅ **最重要的匹配依據**：
- **中文條文內容（D 欄）**是 RAG 語意搜尋的主要目標
- 條文應詳細、具體、包含領域關鍵詞

✅ **重要的加分項**：
- **類別 + 行為準則 + 關鍵字（A/B/C 欄）**在 Rerank 階段權重高（12）
- 即使 RAG 相似度一般，Rerank 加分可以大幅提升最終分數

⚠️ **需注意的情況**：
- 如果附件三只有條文沒有關鍵字，分數會偏低（可能黃色或紅色）
- 題目過於簡短或模糊，容易匹配到泛用條文（會被扣分）

🎯 **最佳實踐建議**：

1. **附件三（知識庫）填寫**：
   - ✅ D 欄條文內容：詳細完整，包含具體做法和背景
   - ✅ C 欄關鍵字：至少填入 2-5 個核心關鍵字（換行分隔）
   - ✅ A/B 欄類別和行為準則：明確分類
   - ✅ E/F 欄部門和現況：提供實際執行資訊

2. **附件二（問卷）填寫**：
   - ✅ 題目應明確具體，避免過於籠統
   - ✅ 包含領域關鍵詞（如「消防」、「急救」、「環境」）
   - ✅ 避免只用泛用詞（如「管理」、「政策」、「流程」）

3. **人工審核重點**：
   - 🟡 **黃色題目**：抽查 20-30%，確認匹配是否合理
   - 🔴 **紅色題目**：100% 人工填寫
   - 🟢 **綠色題目**：可信賴度高，但建議抽查 5-10%

### 評分流程總覽

```
附件二題目
  ↓
RAG 語意搜尋（Top-20 候選）
  ↓
Rerank 二次排序（C欄×12 + D欄×5 - 扣分）
  ↓
關鍵字驗證（min_match=1）
  ↓
相似度分數判斷
  ├─ ≥ 70% → 🟢 綠色（高信心）
  ├─ 55-69% → 🟡 黃色（中信心）
  │            ↓
  │         LLM 升級？
  │          ├─ Y → 🟢 綠色
  │          └─ N → 🟡 黃色
  └─ < 55% → 🔴 紅色（低信心）

關鍵字不匹配 → 🔴 紅色（未匹配）
```
