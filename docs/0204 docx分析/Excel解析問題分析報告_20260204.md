## 🔍 根本原因分析

### 問題 1：供应商社会责任承诺函_測試.xlsx 無法解析

#### ❌ 原因：欄位結構錯誤（少了「類別」欄位，導致所有欄位向左錯位一格）

**程式預期的檔案結構：**

| 欄位 | 欄位名稱 | 說明 | 程式用途 |
|------|----------|------|----------|
| A 欄 | 類別 | Labor 勞工、Health & Safety 健康與安全 | 分類標籤 |
| B 欄 | 條款編號 | B.1.1, B.1.2, C.7.1 | **建立索引** |
| C 欄 | 中文條文內容 | 題目文字內容 | **用來比對資料庫** |
| D 欄 | 鑑別權責部門 | （空白，待填入） | **AI 填入答案** |
| E 欄 | 目前現況/可能影響 | （空白，待填入） | **AI 填入答案** |

**測試檔案的實際結構：**

| 欄位 | 欄位名稱 | 說明 | 問題 |
|------|----------|------|------|
| A 欄 | 條款 | 1.劳工标准、1.1自由择业 | ❌ 缺少「類別」欄位 |
| B 欄 | 中文條文內容 | 题目文字內容 | ❌ 程式當成「條款編號」 |
| C 欄 | 鑑別權責部門 | （空白） | ❌ 程式當成「題目」但是空的！ |
| D 欄 | 目前現況/可能影響 | （空白） | ❌ 程式當成「權責部門」寫入 |
| E 欄 | 鑑定結果 | （空白） | ❌ 程式當成「現況」寫入 |

#### 程式執行流程：

```python
# rpa_security_c.py 第 1499-1550 行

for row in range(3, ws.max_row + 1):
    clause = ws[f"B{row}"].value  # ❌ 讀到「中文條文內容」（長篇文字）

# 步驟 2: 讀取題目（C 欄）
for row in range(3, ws.max_row + 1):
    question = ws[f"C{row}"].value  # ❌ 讀到「鑑別權責部門」（空的！）
    
    if not question or not str(question).strip():
        continue  # ❌ 因為 C 欄是空的，所有題目都被跳過
```

#### 實際結果：

- 程式讀取 C 欄（鑑別權責部門）當作題目，但這欄本來就是空的
- 所有題目都被判定為「空白題目」而跳過
- **0 筆匹配，完全無法解析**

### 問題 2：附件一. AI判斷測試結果_佳世達.xlsx 匹配率低

#### ⚠️ 原因：檔案格式正確，但題目內容與資料庫不匹配

**檔案結構：** ✅ 正確

- A 欄：類別 ✓
- B 欄：條款編號 ✓（但大部分是 None）
- C 欄：中文條文內容 ✓
- D 欄：鑑別權責部門 ✓
- E 欄：目前現況/可能影響 ✓

**題目格式：**

```
(1)在商業活動中遵守所有適用的法令與商業道德，不得參與不正當競爭...
(2)向買方提交ISO14001證書或明確的環境治理方案...
(3)為員工提供健康、安全的工作環境，並在危險工作區及有害物質、危險商品上設置醒目標識...
```

**特徵：**

- 題目格式為中文敘述性問題
- 使用 (1), (2), (3)... 編號
- 缺少條款編號（B 欄大部分為 None）
- 問題描述較為概括性

**匹配結果：**

- 總題數：14 題
- 成功匹配：2 題（匹配到「職安」）
- 未匹配：12 題（顯示「未匹配」）
- 匹配率：**14.3%**

**可能原因：**

1. 資料庫（附件三）的條文內容與這些題目的敘述方式不同
2. 缺少條款編號，無法利用索引加速匹配
3. RAG 語意搜尋可能沒有找到相似的條文內容
4. 信心閾值設定可能過高（< 55 視為紅色，≥ 70 視為綠色）

1. 在 A 欄前插入一列，新增「類別」欄位
2. 將現有欄位向右移動一格
