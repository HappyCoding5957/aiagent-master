- 「聚會結社」vs「結社自由」用詞不一致
- 「ISO14001」vs「ISO 14001」格式不一致

**影響**：
- ❌ 語意相近但用詞不同的內容無法匹配

**建議**：
在 `expand_question_for_rag()` 函數中加入同義詞替換：


### 問題 5：多主題題目處理不佳

**現象**：
```
題目：「(13)不參與非法競爭和腐敗活動，並遵守智慧財產權法律」
包含兩個主題：「反貪腐」+ 「智慧財產權」
```

**影響**：
- ❌ 混合查詢導致相似度降低
- ❌ 無法同時匹配兩個主題

**建議**：
1. **偵測多主題**：檢測「並」、「及」、「和」等連接詞
2. **拆分查詢**：分別查詢兩個主題
3. **結果合併**：將兩次查詢結果合併回覆

```python
def split_multi_topic_question(question: str) -> list:
    """
    偵測並拆分多主題題目
    """
    # 偵測分隔詞
    separators = ['並', '及', '和', '，並', '、並', '以及']

    for sep in separators:
        if sep in question:
            parts = question.split(sep, 1)
            if len(parts) == 2:
                return [parts[0].strip(), parts[1].strip()]

    return [question]  # 單一主題

# 使用範例
topics = split_multi_topic_question(question)
if len(topics) > 1:
    # 分別查詢
    results1 = call_rag_semantic_search(topics[0], ...)
    results2 = call_rag_semantic_search(topics[1], ...)
    # 合併結果
    results = merge_results(results1, results2)
```
