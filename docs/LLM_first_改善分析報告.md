  - 可能是 chunk 切割問題，導致內容被截斷
- **改善建議**:
  1. 檢查附件三上傳時的 chunk 策略
  2. 確保 D/E 欄完整內容都被包含在同一個 chunk
  3. 考慮增加 chunk overlap

### 題 9: 不得歧視（種族/性別/年齡等）

- **現況影響**: ❌ 不完全匹配

### 題 12: ISO14001 證書/環境治理

## ❌ 完全不正確的題目（3 題）

- **權責部門**: ❌ 未匹配（請人工判定）
- **現況影響**: ❌ 知識庫無相關資料或語意不匹配

  2. 建議在前處理階段過濾「承諾聲明」類題目

### 題 14: 非法競爭/腐敗/智慧財產權
- **權責部門**: ❌ 智權（應該是「法務、智權」）
- **現況影響**: ❌ 只提到智慧財產權，缺少反貪腐
  - **新答案**: "【智慧財產權】1. 公司訂有(SA-23-07001)專利管理辦法：確保本公司"
  - **正確答案**: "1.制訂(SHS120009)反貪腐遵循辦法富采集團誠信與道德行為管理辦法(E"
- **問題分析**:
  - 題目包含 3 個概念：非法競爭、腐敗、智慧財產權
  - LLM only 抓到「智慧財產權」，遺漏「腐敗」
  - RAG 因此找錯條文（只找智權，沒找反貪腐）
- **改善建議**:
  1. **LLM prompt 改進**：要求完整提取所有子概念

  3. **topic_tags 要包含**：corruption, unfair_competition, intellectual_property
  4. **rerank 改進**：當題目有多個概念時，優先選擇涵蓋最多概念的條文

### 題 15: RBA 稽核同意
- **權責部門**: ❌ 業務（應該是 `-`）
- **現況影響**: ❌ 內容不對

  - 系統找到 RBA 相關條文，但正確答案是不回答
- **改善建議**:
  1. **前處理階段識別「承諾聲明」類題目**
  2. 關鍵詞：「承諾」「同意」「知悉並理解」
  3. 對此類題目標記為「無需回答」

## 🔧 綜合改善建議

### 1. **LLM-first Schema 改進（高優先級）**

#### 1.1 多概念題目處理
```python
# 修改 LLM prompt
system_prompt = """
你是職安問卷的「結構化抽取器」。

重要：如果題目包含多個獨立概念（如：競爭 + 腐敗 + 智財），
必須將每個概念都列入 must_have_terms 和 topic_tags。

範例：
題目：「不參與非法競爭和腐敗活動，並遵守智慧財產權法律」
✅ must_have_terms: ["非法競爭", "腐敗", "智慧財產權"]
✅ topic_tags: ["unfair_competition", "corruption", "intellectual_property"]
❌ must_have_terms: ["智慧財產權"]  # 太狹隘！
"""
```

#### 1.2 承諾聲明識別
```python
# 在 normalize_question_to_schema 前加入前處理
def is_commitment_statement(question: str) -> bool:
    """識別「承諾聲明」類題目（不需實質回答）"""
    commitment_keywords = [
        "承諾", "同意", "知悉並理解", "充分理解",
        "乙方完全", "供應商確認"
    ]
    return any(kw in question for kw in commitment_keywords)

# 使用
if is_commitment_statement(question):
    log_lines.append("[前處理] 承諾聲明題目，標記為無需回答")
    ws[f"D{row_idx}"] = clean_excel_text("-")
    ws[f"E{row_idx}"] = clean_excel_text("-")
    continue
```

### 2. **RAG & Rerank 改進（中優先級）**

#### 2.1 Chunk 策略優化
- **問題**：F 欄內容被截斷
- **建議**：
  1. 增加 chunk size 或 overlap
  2. 確保 D/E 欄完整內容在同一個 chunk
  3. 使用語意邊界切割（不要硬切）

#### 2.2 Rerank 多概念評分
```python
# 在 rerank_rag_candidates 中加入
def multi_concept_score(candidate, must_have_terms):
    """多概念題目：檢查候選條文是否涵蓋所有概念"""
    matched_concepts = 0
    for term in must_have_terms:
        if term in candidate["behavior"] or term in candidate["article"]:
            matched_concepts += 1

    coverage_ratio = matched_concepts / len(must_have_terms)

    # 涵蓋度加分
    if coverage_ratio >= 0.8:  # 涵蓋 80% 以上概念
        return 20
    elif coverage_ratio >= 0.5:
        return 10
    else:
        return -10  # 涵蓋不足，扣分
```
