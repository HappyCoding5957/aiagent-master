## 🐛 連線問題排查

### 如果出現 "ERR_CONNECTION_REFUSED"

#### 1. 檢查服務是否運行
```bash
# SSH 連線到 10.100.40.5
ssh lladm@10.100.40.5

# 檢查 Docker 容器狀態
cd /home/lladm/frank/n8n/客戶問卷RPA/attachment3-manager
docker compose ps

# 應該看到兩個容器都是 "Up" 狀態
```

#### 2. 檢查端口監聽
```bash
# 檢查端口是否開放
netstat -tlnp | grep -E ":(4200|8000)"

# 應該看到：
# 0.0.0.0:4200 ... LISTEN
# 0.0.0.0:8000 ... LISTEN
```

#### 3. 測試本機訪問
```bash
# 測試後端
curl http://localhost:8000/

# 測試前端
curl http://localhost:4200/
```

#### 4. 重啟服務
```bash
cd /home/lladm/frank/n8n/客戶問卷RPA/attachment3-manager
docker compose restart
```

### 如果頁面空白或無法載入

#### 1. 清除瀏覽器快取
- 按 `Ctrl + Shift + Delete`
- 清除快取和 Cookies
- 重新整理頁面

#### 2. 檢查前端日誌
```bash
docker compose logs frontend
```

#### 3. 重新建置前端
```bash
docker compose down
docker compose up -d --build frontend
```

### 如果 API 無法連接

#### 1. 檢查後端日誌
```bash
docker compose logs backend
```

#### 2. 測試 API 端點
```bash
# 測試狀態 API
curl http://10.100.40.5:8000/api/status

# 測試進度 API
curl http://10.100.40.5:8000/api/progress
```

#### 3. 檢查資料庫連線
```bash
# 在容器內測試資料庫連線
docker exec -it attachment3-backend bash
psql -h 10.100.40.5 -p 8002 -U dgtk -d dgtk
```

## 📱 使用方式

### 1. 上傳附件三

1. 開啟瀏覽器訪問 `http://10.100.40.5:4200`
2. 點擊「選擇附件三.xlsx」按鈕
3. 選擇本機的 Excel 檔案
4. 點擊「🚀 上傳並更新知識庫」
5. 觀察進度條變化
6. 等待上傳完成

### 2. 查看狀態

- 頁面會自動顯示當前知識庫狀態
- 包含：檔案名稱、資料筆數、最後更新時間、PDF ID
- 點擊「🔄 重新整理狀態」手動更新

### 3. 刪除知識庫

1. 點擊「🗑️ 刪除附件三知識庫」按鈕
2. 確認刪除操作
3. 等待刪除完成
